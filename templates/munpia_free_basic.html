텔레그램 연결 순서
  1. BotFather에서 /newbot으로 전용 봇을 만듭니다. /mybots에서 실제 @사용자명을 확인합니다.
  2. 텔레그램 채널 → 채널 관리(편집) → 관리자 → 관리자 추가를 누른 뒤 @봇사용자명을 검색합니다. 기존 관리자 목록의 검색창과 다릅니다.
  3. 공개 채널은 @채널사용자명을 입력합니다. 봇 사용자명이나 채널의 한글 표시 이름을 입력하지 마세요.
  4. 비공개 채널은 게시물을 우클릭 → 메시지 링크 복사를 선택합니다. 예: https://t.me/c/1234567890/5에서 채널 번호는 1234567890입니다. FF에 입력할 ID는 -1001234567890입니다. 정확한 계산식은 -(1000000000000 + 채널 번호)이며 마지막 /5는 게시물 번호입니다. t.me/+… 초대 링크는 사용할 수 없습니다.
  5. 토큰·채널을 입력하고 수신 사용 → 텔레그램 설정 저장 → 채널 연결 확인을 누릅니다.
  6. 채널에 새 문피아 링크를 게시하고 링크 지금 확인을 누릅니다. 설정 탭을 열면 추가된 작품 번호를 확인할 수 있습니다.
